# Курсовая работа «Gadget Hub»

## О проекте

Gadget Hub — учебный интернет-магазин электроники. В проекте есть главная страница, авторизация, каталог с фильтрацией и сортировкой, карточка товара, корзина, оформление заказа и история заказов

Клиентская часть написана на Vue 3, серверная часть — на Node.js и Express. Товары и заказы хранятся в JSON-файлах, а корзина сохраняется в localStorage браузера

## Запуск

Установите Node.js версии 20.19 или новее. Откройте папку `coursework` в WebStorm, откройте встроенный терминал и выполните:

```bash
npm install
npm run dev
```

После запуска откройте `http://localhost:5173`. Сервер API работает по адресу `http://localhost:3000`
