# Лабораторная работа 5

## Задание

Реализовать механику списка в книжном интернет-магазине. Создать компонент
списка в виде дерева. Добавить возможность скрывать/раскрывать ветки. Структура
дерева: Автор → Издательство → Жанр → Название книги.

## Реализация

Приложение написано на React с использованием Vite. Состояние дерева и раскрытых
веток сохраняется в `localStorage`. Реализована форма для добавления новых книг,
которая автоматически обновляет структуру дерева, создавая недостающие уровни
(автора, издательство, жанр) при необходимости. Компонент `TreeNode` использует
рекурсивный рендеринг. Все классы названы в kebab-case, ID-селекторы и
`!important` не используются.

## Запуск

1. Выполнить `npm install`
2. Выполнить `npm run dev`
3. Открыть указанную в консоли ссылку в браузере.
